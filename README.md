# 線上合約簽名
前端以Vue.js開發，發送取得資料的串接部分已寫好，但尚無後端段應處理，完成度80%，請按照以下步驟測試：<br>
<ol>
  <li>建立合約：<br>
    <ul>
      <li>請先點擊左側「選擇檔案」來添加合約圖片，右側合約畫會即時顯示上傳結果，如有錯誤可點擊右側操作中的「刪除」來刪掉單張圖片，也可點擊左側左側上傳圖片的「清空」來清除全部圖片</li>
      <li>完成檔案上傳後再點擊設定簽名的「添加」按鈕，輸入期望的簽名區寬高及顯示位置，合約畫面中就會多一個簽名區塊，可以拖拉它調整位置或是點擊「點我編輯」修改寬高等或刪除，若要刪除全部簽名，可點擊簽名設定的「清空」</li>
      <li>簽名添加時預設位置為當前合約畫面顯示的最左上角，所以可以先轉動合約畫面至大約位置再添加簽名</li>
      <li>在簽名時，客戶須簽完所有簽名區才能提交合約，所以簽名區請添加必要的量即可</li>
      <li>另外，可能因為簽名位置設定超出合約畫面而無法顯示，因此建議新增流程是:圖片>簽名，刪除流程是:簽名>圖片</li>
    </ul>
  </li>
  <li>客戶簽名確認：<br>
      <ul>
        <li>簽名：點擊各簽名區開啟簽名視窗，手寫後儲存，手寫當下要修改則可點擊「清空簽名區」，儲存後如需修改則請再次點擊簽名區，手寫馨簽名並儲存即可</li>
        <li>送出資料：所有簽名都完成後，點擊最下方「送出合約」即完成簽名確認動作</li>
        <li>儲存：送出合約後狀態將被改成已確認，此時會出現「列印合約」按鈕，點擊即可對當前畫面進行整頁截圖並儲存成圖片</li>
      </ul>
  </li>
</ol>
